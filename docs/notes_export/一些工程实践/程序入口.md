# 程序入口

main函数、循环架构、初始化与释放等，都不应该全部交给用户来做。同时也是为了入口的简洁性和规范性，引擎可以定义这样的模式：

```c
// .h
typedef struct {
	const char* name;
	const char* version;
	int w_real;
	int h_real;
	int w_logic;
	int h_logic;
	bool condition;
	...
} Application;

#define APP_START(app_name, version, w_real, h_real, w_logic, h_logic) \
int main(void) { \
	Application app = (Application) { (app_name), (version), (w_real), (h_real), (w_logic), (h_logic), true };

#define APP_END() \
__app_exit(app); \
return 0; }
```

**使用**：

```c
// main.c

APP_START("maple", "0.1.0", 1920, 1080, 1280, 720)
	ADD_PLUGIN(&app, default_plugin);
	ADD_PLUGIN(&app, maple_plugin);
	MAIN_LOOP(120);
APP_END()
```

其中ADD_PLUGIN宏是添加[插件](插件.md)的宏。推荐入口只保留这个接口的使用。
