# 资源管理

资源是全局单例的游戏数据，通过统一的接口进行存取。

# 资源结构体

首先是资源结构体的声明和实现。由于是全局单例，所以实现起来很容易。类似于面向对象语言中的“类”，字段用`static`​设置成“**私有**”，定义专用的**设置**Set和**获取**Get两种方法。还有一个用于初始化整个结构体的Init方法。

```c
#define DECLARE_RESOURCE_BEGIN() typedef struct {
#define DECLARE_RESOURCE_END(res_name) } res_name; \
void init_resource_##res_name(res_name res); \
void set_resource_##res_name(size_t offset, const void* value, size_t value_size); \
res_name get_resource_##res_name(void); \
const res_name* get_resource_addr_##res_name(void);

#define IMPL_RESOURCE(res_name) \
static res_name __res_##res_name; \
static bool __initialized_##res_name = false; \
void init_resource_##res_name(res_name res) { \
	if (__initialized_##res_name) return; \
	__res_##res_name = res; \
	__initialized_##res_name = true; \
} \
void set_resource_##res_name(size_t offset, const void* value, size_t value_size) { \
	memcpy((void*)&__res_##res_name + offset, value, value_size); \
} \
res_name get_resource_##res_name(void) { \
	return __res_##res_name; \
} \
const res_name* get_resource_addr_##res_name(void) { \
	return &__res_##res_name; \
}
```

> Init处可以插入一条警告，尝试多重初始化。

**使用**：

```c
// .h
DECLARE_RESOURCE_BEGIN()
	int a;
	int b;
DECLARE_RESOURCE_END(Score)

// .c
IMPL_RESOURCE(Score)
```

存取方法用宏统一风格：TODO 数字类型，长度不同时

```c
#define SET_RES(res_name, field, value) \
do { \
	typeof(((res_name*)0)->field) _tmp = (value); \
	set_resource_##res_name(offsetof(res_name, field), &_tmp, sizeof(_tmp)); \
} while(0)

#define GET_RES(res_name, field) \
(get_resource_##res_name().field)
#define GET_RES_FULL(res_name) \
get_resource_##res_name()
#define GET_RES_FULL_ADDR(res_name) \
get_resource_addr_##res_name()
```

> 关于**offset**宏，定义：
>
> ```c
> #define offsetof(type, v) (&(((type*)0)->v))
> ```

> 关于**​`typeof`​**​关键字，这是GNU的一个扩展，GCC和Clang完全支持（用clang或clang++。clang-cl很不一样，很可能不支持）。C23也支持。它**根据变量标识符得到变量类型**。类似于C++中的`decltype`关键字。

# 资源注册

注册，就是在程序开始时注入自己的具体资源。Init函数确保了初始化仅做一次（**幂等**）。

```c
#define REG_RESOURCE(res_name, res) init_resource_##res_name(res)
```
