# 插件

如果将所有Application注册相关的代码堆在一块，会显得臃肿。这个时候就需要对它们进行“打包”，这种组织者就叫**插件**。

插件被视为函数，仅在Application开始时被顺序调用，以实现注册行为。

```c
// .h
typedef void(*PluginFn)(Application* app);
// In Application
PluginFn* plugins; // 同样初始化为NULL
```

添加插件的接口：

```c
// .h
#define ADD_PLUGIN(app, plugin) __app_add_plugin((app), (plugin))

// .c
void __app_add_plugin(Application* app, PluginFn plugin) {
	arrput(app->plugins, plugin);
}
```

在APP_START里，添加插件的实际“装配”语句：

```c
// In APP_START
for (int i = 0; i < arrlen(plugins); i++) { \
	app.plugins[i](&app); \
} \
```
