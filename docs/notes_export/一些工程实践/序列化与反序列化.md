# 序列化与反序列化

游戏对象的保存（持久化）与恢复、网络传输等都需要用到**序列化(Serialize)** 与**反序列化(Deserialize)** 的思想。

序列化将对象转换为方便传输的**流**，而反序列化将流还原为对象。

可以明确的是，序列化和反序列化是成对存在的。一个可被序列化的对象一定能从对应的流反序列化，反之亦然。

像这样，多种抽象操作绑定在一起的关系，可以用**接口**来描述。

> **==注意==**，以下将函数指针注入结构体的方式已经**过时**，**建议使用更优雅的**​**[独立成员函数配套WITH宏的写法](siyuan://blocks/20260808100556-sg77s18)**。

# 接口定义

在C语言中，可以用嵌套结构体的方式来表达“继承”，因此实现一个接口首先要包含这个接口。而接口的操作则被以函数指针的形式包含在接口结构体内部，由外部“注入”具体实现。

```c
#define IMPL_INTERFACE(interface, type) IMPL_INTERFACE_##interface(type)

typedef char* Stream;
#define IMPL_INTERFACE_Serde(type) \
struct { \
	Stream serialize(struct type* obj); \
	bool deserialize(struct type* obj, Stream stream); \
} serde
```

# 注入

比如有一个Player组件，需要实现Serde接口，可以这么做：

```c
// .h
DECLARE_COMP_BEGIN(Player)
	IMPL_INTERFACE(Serde, Player);
	int hp;
	int def;
	float atk;
	int level;
	const char* name;
DECLARE_COMP_END(Player)

// .c
IMPL_COMP(Player)
```

定义相关注入操作：

```c
#define INJECT_IMPLIMENTS_Serde(obj, ser, de) \
do { \
	(obj)->serde.serialize = (ser); \
	(obj)->serde.deserialize = (de); \
} while(0)
```

这个宏在每次组件生成时调用一次即可完成注入。

# 序列化实现

序列化的实现方式有很多，其中最简单的方式就是单纯地将对象数据看作流。这是因为结构体和流底层都是一个个字节的方式存储的，在这一层面上，两者是可以“等价转换”的。(这就是前面将`Stream`​视为`char`的数组的原因)

考虑到结构体有“对齐”机制，而序列化最终是要存储到媒体或者发送到网络的，对空间占用较为敏感。故只将有效数据转换成流，那些对齐的字节应当跳过。所以建议**逐字段序列化**，而非简单地将结构体逐字节序列化。~~而且这样在反序列化时不必专门分辨哪些是对齐空间，逻辑上也方便许多。~~

> 事实上逐字段序列化根本原因**只有空间占用问题**，所谓“对齐空间”其实也是无需分辨的，整个结构体和流之间只用memcpy就可以流畅做到（浅拷贝）。深拷贝就必须逐字段了。见下。

还有一个细节，序列化的有效数据是指具体的值，而不是“地址”。地址伴随着程序在内存中的浮动而改变，是动态的，不应该被持久化存储。如果地址指向的是像接口之类的函数，这些地址应当跳过。但有一类地址不能被简单跳过，而应当被专门转换成具体的内容进行存储。比如指向一个字符串、一个容器等等的字段，应该**将内容解析出来**，按顺序一起存储，并且加上特殊终结符的方式表达这段不定长数据的结尾。

具体类型的序列化由用户自己实现。实现示例：

```c
Stream serialize(Player* obj) {
	Stream stream = NULL;
	for (int i = 0; i < sizeof(obj->hp); i++) {
		arrput(stream, ((char*)&(obj->hp))[i]);
	}
	for (int i = 0; i < sizeof(obj->def); i++) {
		arrput(stream, ((char*)&(obj->def))[i]);
	}
	for (int i = 0; i < sizeof(obj->atk); i++) {
		arrput(stream, ((char*)&(obj->atk))[i]);
	}
	for (int i = 0; i < sizeof(obj->level); i++) {
		arrput(stream, ((char*)&(obj->level))[i]);
	}
	for (int i = 0; obj->name[i] != '\0'; i++) {
		arrput(stream, obj->name[i]);
	}
	return stream;
}
```

以上代码还能精简一点：

```c
#define SERIALIZE_FIELD_VALUE(stream, obj, field) do { \
	for (int i = 0; i < sizeof((obj)->(field)); i++) { \
		arrput(stream, ((char*)&((obj)->(field)))[i]); \
	} \
} while(0)
#define SERIALIZE_FIELD_STRING(stream, obj, charptr) do { \
	for (int i = 0; (obj)->(charptr)[i] != '\0'; i++) { \
		arrput(stream, (obj)->(charptr)[i]); \
	} \
	arrput(stream, '\0'); \
} while(0)

Stream ser_player(Player* obj) {
	Stream stream = NULL;
	SERIALIZE_FIELD_VALUE(stream, obj, hp);
	SERIALIZE_FIELD_VALUE(stream, obj, def);
	SERIALIZE_FIELD_VALUE(stream, obj, atk);
	SERIALIZE_FIELD_VALUE(stream, obj, level);
	SERIALIZE_FIELD_STRING(stream, obj, name);
	return stream;
}

// 更通用的容器序列化宏
#define SERIALIZE_FIELD_ARRAY(stream, obj, array_ptr, array_len) do { \
	for (int i = 0; i < array_len; i++) { \
		for (int j = 0; j < sizeof((obj)->(array_ptr)[i]); j++) { \
			arrput(stream, ((char*)&((obj)->(array_ptr)[i]))[j]); \
		} \
	} \
} while(0)
```

> 产生的流，用到堆区数据，用完后记得`arrfree()`释放。

# 反序列化实现

反序列化时有字段的直接访问，无须担心数据被错误地填至对齐空间的问题。

具体类型的反序列化由用户自己实现。实现示例：

```c
#define DESERIALIZE_FIELD_VALUE(obj, field, stream, cursor, fail_label) do { \
	if (cursor <= arrlen(stream) - sizeof((obj)->(field))) { \
		for (int i = 0; i < sizeof((obj)->(field)); i++) { \
			((char*)&((obj)->(field)))[i] = stream[i + cursor]; \
		} \
		cursor += sizeof((obj)->(field)); \
	} else { \
		goto fail_label; \
	} \
} while(0)
#define DESERIALIZE_FIELD_STRING(obj, charptr, stream, cursor, fail_label) do { \
	size_t len = strlen(stream + cursor); \
	if (cursor <= arrlen(stream) - len - 1) { \
		for (int i = 0; i < len; i++) { \
			arrput((obj)->(charptr), (stream + cursor)[i]); \
		} \
		cursor += len + 1; \
	} else { \
		goto fail_label; \
	} \
} while(0)

bool de_player(Player* obj, Stream stream) {
	size_t cursor = 0;
	DESERIALIZE_FIELD_VALUE(obj, hp, stream, cursor, Fail);
	DESERIALIZE_FIELD_VALUE(obj, def, stream, cursor, Fail);
	DESERIALIZE_FIELD_VALUE(obj, atk, stream, cursor, Fail);
	DESERIALIZE_FIELD_VALUE(obj, level, stream, cursor, Fail);
	DESERIALIZE_FIELD_STRING(obj, name, stream, cursor, Fail);
	return true;
	Fail:
	return false;
}

// 更通用的容器序列化宏
#define DESERIALIZE_FIELD_ARRAY(obj, array_ptr, array_len, stream, cursor, fail_label) do { \
	if (cursor <= arrlen(stream) - array_len) { \
		arrfree((obj)->(array_ptr)); \
		(obj)->(array_ptr) = NULL; \
		arrsetcap((obj)->(array_ptr), array_len); \
		for (int i = 0; i < array_len; i++) { \
			for (int j = 0; j < sizeof((obj)->(array_ptr)[i]); j++) { \
				((char*)&((obj)->(array_ptr)[i]))[j] = stream[i * sizeof((obj)->(array_ptr)[i]) + j]; \
			} \
		} \
	} else { \
		goto fail_label; \
	} \
} while(0)
```

注意**顺序**一定要与Serialize里的**保持一致**！

反序列化调用反馈成功与否。因为反序列化是有可能失败的。失败的话就返回`false`。
