# 事件系统

系统常常不是孤立存在的，系统之间经常发生交流。交流的“信使”被抽象成**事件**。事件实现方式分为两种，一种是对象式（**消息**），另一种是订阅式（**观察者**）。

# 消息传递机制

消息机制将发送者与接收者解耦，两者都不需要知道对方的存在，只需知道自己发送/处理的消息。

## 消息结构体

定义消息体：

```c
typedef struct {
	Entity source;
	uint32_t msg_id;
	void* data;
} Message;
```

> 其中msg_id根据传入的const char*（消息名称字符串）自动生成的，具体生成原理类似[带缓存机制的组件ID生成器](siyuan://blocks/20260713002959-7a0kf1w)。其中消息名称字符串通过便捷宏传入，并用(void)sizeof保证类型安全。对应的获取器宏为`MSG_ID()`。具体细节就略过了。

## 缓冲区交换

Application内部维护两个消息队列。所有**当前帧产生的消息放到下一帧消息队列**，而下一帧PreUpdate阶段开始时就将下一帧消息队列与当前帧消息队列的**指针互换**，然后**清空**下一帧消息队列。  
**即**：所有当前帧产生的消息到下一帧才被处理，而当前帧未处理掉的消息将被丢弃。

```c
// In Application
Message* next_messages; // 初始化为NULL
Message* current_messages; // 初始化为NULL
```

消息队列的**清空**属于内置逻辑操作，应该被包装成一个系统，在Main Loop之前就要注册到PreUpdate里，并确保在系统列表的最前面。

Application可以**自己维护一个**​**​`default_plugin`​**​ **，将所有的内置注册操作放到里面。**

但是注册的系统又需要访问Application实例才能进行操作，而系统函数本身签名是不支持的。

所以，采用资源注入的方式。假设在APP_START已经注册Application实例到特定资源。通过`GET_RES()`​获取实例app。并且有个便捷宏包装：`GET_APP()`。

```c
void __message_buf_swapper(void) {
	Application* app = GET_APP();
	Message* temp = next_messages;
	app->next_messages = app->current_messages;
	app->current_messages = temp;
	arrsetlen(next_messages, 0);
}

void default_plugin(Application* app) {
	arrins(app->schedules[PreUpdate], 0, __message_buf_swapper); // 注册消息缓冲区交换系统
}
```

## 发送与接收

消息由消息发送者*MessageSender*发送到消息队列的末尾。消息队列产生的消息由消息处理者*MessageReader*消费。具体函数仍是系统，由用户定义。

规定用户使用自定义消息之前，先对消息进行“注册”：

```c
// .h
#define DEFINE_MESSAGE(name) struct name{};

#define REG_MESSAGE(message_name) \
do { \
	(void)sizeof(struct message_name); \
	shput(__message_reg, #message_name, gen_message_id(#message_name)); \
} while(0)
```

`REG_MESSAGE()`​宏中的`(void)sizeof(struct message_name);`是用来编译期检测消息名称合法性的。消息名称唯一对应一个消息空结构体，仅作为检查标志，不实际存放数据。用户只有在定义了消息之后才能将消息注册，防止输错。

```c
#define SEND_MESSAGE(app, source, message_name, data) \
do { \
	(void)sizeof(struct message_name); \
	arrput((app)->next_messages, (Message) { (source), MSG_ID(#message_name), (data)}); \
} while(0)
#define RECEIVE_MESSAGE(app, message_name) \
((void)sizeof(struct message_name), receive_message((app), #message_name))

Message receive_message(Application* app, const char* message_name) {
	uint32_t msg_id = MSG_ID(message_name);
	if (msg_id == UINT_MAX) goto End;
	for (int i = 0; i < arrlen((app)->current_messages); i++) {
		if ((app)->current_messages[i].msg_id != UINT_MAX
			&& (app)->current_messages[i].msg_id == msg_id) {
			Message msg = (app)->current_messages[i];
			(app)->current_messages[i].msg_id = UINT_MAX; // 设为非法值，即将队列中的消息设为无效。
			return msg;
		}
	}
	End:
	return (Message) { .source = 0, .msg_id = UINT_MAX, .data = NULL };
}
```

`receive_message()`​中采用`(app)->current_messages[i].source = 0;`​而不是直接删除数组元素的做法能避免移动后续元素，节省很多时间开销。每次拿取一个消息后，仅需判断这个消息的**​`msg_id`​**​**字段是否合法（非UINT_MAX）** 来作为消息是否合法的依据。

# 观察者机制

观察者作为函数挂载到Application实例上或者特定实体上。当特定事件（该机制下的事件称作“**信号**”）被触发后，立即执行观察该事件的所有观察者。

也就是说，观察者有两种形式：**全局挂载**和**实体挂载**。触发全局信号时，首先执行全局的，再执行实体特定的；而触发实体信号时，仅执行实体特定的。

## 信号

观察者的“挂载”，本质上就是与所关心的信号类别的“对接”。

首先是信号定义，信号id单独视作int而不是特定枚举类型方便扩展，Signal作为内置枚举量：

```c
typedef int SignalId;

enum {
	SIG_INVALID,

	SIG_Button_Clicked,
	SIG_Button_Hovered,
	SIG_Button_Entered,
	SIG_Button_Exited,

	...

	BUILTIN_SIGNAL_CUSTOM
};
```

与[SDL自定义枚举](siyuan://blocks/20260722090639-ug7ofl1)类似，用户可以扩展内置Signal枚举，以定义自己的信号枚举。

## 事件结构体

然后定义事件结构体：

```c
typedef struct {
	SignalId sid;
	void* data;
} Event;
```

## 观察者

有了事件的存取方法，接下来就是观察者的设计。

两类观察者的行为不同，所以区分不同的结构体：

```c
// .h
typedef void(*G_ObserverFn)(Application* app, Event event);
typedef void(*E_ObserverFn)(Entity source, Event event);
```

---

全局挂载的观察者，在全局事件触发后，根据`sid`​筛选并顺序执行。可以采用单一动态数组和**哈希表与动态数组结合**两种方式。为了减少筛选开销和分离不同信号取向的观察者，这里采取后者。

```c
// .h
typedef struct {
	SignalId key;
	G_ObserverFn* g_fns;
} G_ObserverEntry, *G_ObserverReg;

// In Application
G_ObserverReg g_observer_reg; // 初始化为NULL
```

**添加全局观察者**：

```c
#define ADD_GLOBAL_OBSERVER(app, signal_id, g_observer_fn) \
__app_add_global_observer((app), (signal_id), (g_observer_fn))

void __app_add_global_observer(Application* app, SignalId sid, G_ObserverFn g_fn) {
	if (sid == SIG_INVALID) return; // 非法警告
	ptrdiff_t i = hmgeti(app->g_observer_reg, sid);
	if (i >= 0) {
		arrput(app->g_observer_reg[i].g_observers, g_fn);
	} else {
		G_ObserverFn* g_fns = NULL;
		arrput(g_fns, g_fn);
		hmput(app->g_observer_reg, sid, g_fns);
	}
}
```

---

实体挂载的观察者，在实体事件触发后，多了一步使用`sid`​筛选，再使用实体id筛选，并顺序执行。可以采用**两层哈希表**或者哈希表套数组的方式（最内层都是函数数组）。考虑到同一实体可能有多种信号，而同实体同信号的观察者常常只有零到一个，很少有多个，故这里采用前者。

```c
// .h
typedef struct {
	SignalId key;
	E_ObserverEntry* e_observers;
} E_SidEntry, *E_ObserverReg;
typedef struct {
	Entity key;
	E_ObserverFn* e_fns;
} E_ObserverEntry;

extern E_ObserverReg __e_observer_reg;

// .c
E_ObserverReg __e_observer_reg = NULL;
```

**添加实体观察者**：

```c
#define ADD_ENTITY_OBSERVER(entity, signal_id, e_observer_fn) \
__app_add_entity_observer((entity), (signal_id), (e_observer_fn))

void __app_add_entity_observer(Entity entity, SignalId sid, E_ObserverFn e_fn) {
	if (sid == SIG_INVALID) return; // 非法警告
	ptrdiff_t i = hmgeti(__e_observer_reg, sid);
	if (i >= 0) {
		ptrdiff_t j = hmgeti(__e_observer_reg[i], entity);
		if (j >= 0) {
			arrput(__e_observer_reg[i].e_observers[j].e_fns, e_fn);
		} else {
			E_ObserverFn* e_fns = NULL;
			arrput(e_fns, e_fn);
			hmput(__e_observer_reg[i].e_observers, entity);
		}
	} else {
		E_ObserverFn* e_fns = NULL;
		arrput(e_fns, e_fn);
		E_ObserverEntry* e_observers = NULL;
		hmput(e_observers, entity, e_fns);
		hmput(__e_observer_reg, sid, e_observers);
	}
}
```

## 触发

**全局触发**：

```c
#define GLOBAL_TRIGGER(app, event) __app_global_trigger((app), (event))

void __app_global_trigger(Application* app, Event event) {
	if (event.sid == SIG_INVALID) return; // 一次性非法警告
	// 全局挂载触发
	do {
		ptrdiff_t i = hmgeti(app->g_observer_reg, event.sid);
		if (i >= 0) {
			G_ObserverFn* g_fns = app->g_observer_reg[i].g_fns;
			for (int j = 0; j < arrlen(g_fns); j++) {
				g_fns[j](&app, event);
			}
		}
	} while(0);
	// 实体挂载触发
	do {
		ptrdiff_t i = hmgeti(__e_observer_reg, event.sid);
		if (i >= 0) {
			E_ObserverEntry* e_observers = __e_observer_reg[i].e_observers;
			for (int j = 0; j < hmlen(e_observers); j++) {
				Entity entity = e_observers[j].key;
				E_ObserverFn* e_fns = e_observers[j].e_fns;
				for (int k = 0; k < arrlen(e_fns); k++) {
					e_fns[k](entity, event);
				}
			}
		}
	} while(0);
}
```

**实体触发**：

```c
#define ENTITY_TRIGGER(entity, event) __entity_trigger(entity, event)

void __entity_trigger(Entity entity, Event event) {
	if (event.sid == SIG_INVALID) return; // 一次性非法警告
	ptrdiff_t i = hmgeti(__e_observer_reg, event.sid);
	if (i >= 0) {
		ptrdiff_t j = hmgeti(__e_observer_reg[i].e_observers, entity);
		if (j >= 0) {
			E_ObserverFn* e_fns = __e_observer_reg[i].e_observers[j].e_fns;
			for (int k = 0; k < arrlen(e_fns); k++) {
				e_fns[k](entity, event);
			}
		}
	}
}
```
