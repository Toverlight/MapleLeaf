# 系统调度

# 系统定义

ECS中，所有的游戏逻辑被称作**系统**的函数来处理。一个系统函数，唯一的复杂性就是来源于它的“输入”，可能多种多样。C语言特性所限，很难设计应对多样形参的情况。我们可以另辟蹊径，让所有的**外界输入以全局可访问的形式**被随时唤入，而系统函数本身签名“极简化”：**没有形参**，也不需要形参。

```c
// .h
typedef void(*SystemFn)(void);
```

# 调度集

系统之间是有一定的调用顺序的。不同用途的系统被划分到不同的分类里，这些分类在主循环被依次调用，比如**初始化**（配置、资源加载等）、**预处理**（外设输入等）、**固定时间步逻辑**（物理、一般业务等）、**帧相关逻辑**（UI、渲染等）、**后处理**、**清理**等。其中，像初始化和清理全局只会调用一次、固定时间步逻辑在一次循环中甚至可能更新若干次等。

这些划分，被视作不同的**调度**。我们可以定义一个**调度集**去描述它：

```c
// .h
typedef enum {
	Startup,
	PreUpdate,
	FixedUpdate,
	Update,
	PostUpdate,
	Cleanup,

	BUILTIN_SCHEDULE_MAX
} Schedule;
```

系统的不同调度阶段装在一个动态数组里。该数组作为Application的一个字段。下标等于Schedule枚举值。对应元素就是调度的系统列表：

```c
// In Application
SystemFn** schedules;
```

为了灵活性，调度数组和系统列表的初始化移到程序入口执行，避免写死。用户既可以自由添加（注册）自己的系统到对应调度的系统列表，~~还能根据需要自定义新的调度，插入到内建调度数组的任何一个位置~~。不过为了实现简单，暂不考虑自定义调度的情况。

在APP_START宏里，加上对应的初始化：

```c
// 之前先将schedules初始化为NULL
arrsetlen(app.schedules, BUILTIN_SCHEDULE_MAX); \
for (int i = 0; i < arrlen(app.schedules); i++) { \
	app.schedules[i] = NULL; \
	arrsetcap(app.schedules[i], 30); \
} \
```

在APP_END宏里，加上对应的销毁语句：

```c
for (int i = 0; i < arrlen(app.schedules); i++) { \
	arrfree(app.schedules[i]); \
} \
arrfree(app.schedules); \
```

不同的调度可能对应不同的行为。我们将调度行为分为这样三种：**全局单次**、**每帧一次**、**定时一次**。

一个调度行为，接收一个系统列表，对列表内的系统做特定顺序的调度，一般是列表顺序。

```c
// .h
#define SCHEDULE_GLOBAL(phase) \
do { \
	static bool executed = false; \
	if (!executed) { \
		executed = true; \
		SystemFn* systems = app.schedule[(phase)];\
		for (int i = 0; i < arrlen(systems); i++) { \
			systems[i](); \
		} \
	} \
} while(0)

#define SCHEDULE_FRAME(phase) \
do { \
	SystemFn* systems = app.schedule[(phase)];\
	for (int i = 0; i < arrlen(systems); i++) { \
		systems[i](); \
	} \
} while(0)

// in ns
#define SCHEDULE_INTERVAL(phase) \
do { \
	static uint64_t lastpoint = GET_CT_NS(); \
	uint64_t currentpoint = GET_CT_NS(); \
	SystemFn* systems = app.schedule[(phase)];\
	while (currentpoint - lastpoint > GET_FIXED_NS()) { \
		for (int i = 0; i < arrlen(systems); i++) { \
			systems[i](); \
		} \
		lastpoint += GET_FIXED_NS(); \
	} \
} while(0)
```

其中涉及到的一些**全局获取器**（`GET_CT_NS()`​等）会在[资源管理](资源管理.md)中讲。

其中Fixed Time指主循环初始化阶段根据用户设定的fps“注入”的资源，每度过这么长时间固定调用一次“定时一次”调度行为的系统。如果度过的时间超过Fixed Time的**n**倍，那么这段代码可以保证这个调度中的系统都能至少被调用**n**次，即 **“以固定的时间步追上当前时间”** ，以保证逻辑更新的准确性。

定义**主循环**宏。系统内建调度都在里面注册好。

```c
#define MAIN_LOOP(fps) \
do { \
	app.condition = true; \
	double _fps = (double)(fps); \
	if (_fps < 1 || _fps > 165) _fps = 120; \
	const uint64_t nspf = 1.0 / _fps * RATIO_S_NS; \
	SET_RES(Res_TimeFixed, nspf, nspf); \
	SET_RES(Res_TimeFixed, mspf, (double)nspf / RATIO_MS_NS); \
	SET_RES(Res_TimeFixed, spf, (double)nspf / RATIO_S_NS); \
	SCHEDULE_GLOBAL(Startup); \
	static uint64_t last = GET_CT_NS(); \
	while (app.condition) { \
		uint64_t current = GET_CT_NS(); \
		SET_RES(Res_TimeDelta, dns, current - last); \
		SET_RES(Res_TimeDelta, dms, (double)GET_DELTA_NS() / RATIO_MS_NS); \
		SET_RES(Res_TimeDelta, ds, (double)GET_DELTA_NS() / RATIO_S_NS); \
		SCHEDULE_FRAME(PreUpdate); \
		SCHEDULE_INTERVAL(FixedUpdate); \
		SCHEDULE_FRAME(Update); \
		SCHEDULE_FRAME(PostUpdate); \
		uint64_t elapsed = GET_CT_NS() - current; \
		if (elapsed < GET_FIXED_NS()) { \
			DELAY_NS(GET_FIXED_NS() - elapsed); \
		} \
		last = current; \
	} \
	SCHEDULE_GLOBAL(Cleanup); \
} while(0)
```

其中SET_RES是设置资源的宏，同样在[资源管理](资源管理.md)介绍。

# 系统集

首先要实现将一个系统注册到一个特定的调度里的方法：

```c
// .h
#define ADD_SYSTEM(app, schedule, systemfn) __app_add_system((app), (schedule), (systemfn))

// .c
void __app_add_system(Application* app, Schedule schedule, SystemFn system) {
	if (!system) return;
	arrput(app->schedules[schedule], system);
}
```

用户可能有将系统分类组织起来的习惯，这种分类叫作**系统集**。

系统集具体内容由用户决定，引擎仅提供一个内置于Application的存储方案：

```c
#define SYSTEM_SET(app, name, ...) \
({ \
	const SystemFn system_set[] = (const SystemFn[]) { __VA_ARGS__, NULL }; \
	shput((app)->system_sets, #name, system_set); \
	system_set; \
})
```

由于返回的是一个系统函数数组，所以需要适配一个“批量”添加系统的接口：

```c
// .h
#define ADD_SYSTEMS(app, schedule, systems) __app_add_systems((app), (schedule), (systems))

// .c
void __app_add_systems(Application* app, Schedule schedule, const SystemFn[] systems) {
	if (!systems) return;
	for (int i = 0; systems[i] != NULL; i++) {
		arrput(app->schedules[schedule], systems[i]);
	}
}
```

**使用**：

```c
// 单系统注册
ADD_SYSTEM(&app, FixedUpdate, move);
// 系统集多系统注册
ADD_SYSTEMS(&app, PreUpdate, SYSTEM_SET(&app, HangleInput, handle_mouse, handle_keyboard));
// 不通过系统集的多系统注册
ADD_SYSTEMS(&app, Update, (const SystemFn[]) { handle_ui, render });
```
